## Agent Action Receipts (AAR)

Source: https://github.com/oneshot2001/aar, commit `aab2feca93986f92f29f7672dff3464e05163cb5`.
AAR code is licensed under the Apache License 2.0; the AAR specification under CC BY 4.0. Verbatim copies of both licenses, taken from that commit, are in `LICENSES/AAR-Apache-2.0.txt` and `LICENSES/AAR-SPEC-CC-BY-4.0.txt`. AAR contains no `NOTICE` file at that commit.

Material in this package derived from AAR:

- `fixtures/aar/AAR_*.cbor` and `AAR_FIXTURE_CITING_PROOFRECORD.cbor` were generated by AAR's TypeScript harness (`harness/fixtures.ts`), modified with a test-only option hook that is not included here, using AAR's published test keys.
- `fixtures/aar/MUT_*.cbor` are further byte-level mutations of those bundles. Change made: deliberate byte edits for negative testing.
- `AAR_INTEROPERABILITY_CONTRACT.md` refers to field names defined in the AAR specification (`spec/aar-core.cddl`). Attribution: Agent Action Receipts specification, AAR project, CC BY 4.0, https://github.com/oneshot2001/aar. No specification text is reproduced.

AAR is not affiliated with, and has not endorsed, this package.

## RFC 8032 (test vectors only)

`tests/run_tests.py` uses the public key, message and signature of test vectors 1 and 2 from RFC 8032, "Edwards-Curve Digital Signature Algorithm (EdDSA)", Section 7.1, by S. Josefsson and I. Liusvaara (Internet Research Task Force, Crypto Forum Research Group; January 2017; https://www.rfc-editor.org/rfc/rfc8032), as known-answer test data. No RFC 8032 code or prose is included.

RFC 8032 carries this notice:

> Copyright (c) 2017 IETF Trust and the persons identified as the document authors. All rights reserved.
>
> This document is subject to BCP 78 and the IETF Trust's Legal Provisions Relating to IETF Documents (http://trustee.ietf.org/license-info) in effect on the date of publication of this document. Please review these documents carefully, as they describe your rights and restrictions with respect to this document.

Release candidate v0.1.0-rc.1 contained a verifier adapted from RFC 8032 Section 6. It was removed in v0.1.0-rc.2 (see `RELEASE_NOTES.md`).

None are bundled.

- **PyNaCl 1.6.2** (https://pypi.org/project/PyNaCl/1.6.2/, https://github.com/pyca/pynacl), required by `epverify/ed25519_verify.py`. License: Apache License 2.0. PyNaCl's wheels include **libsodium** (https://libsodium.org), Copyright (c) 2013-2026 Frank Denis, ISC License. You install PyNaCl yourself; its license files ship with it. Nothing from PyNaCl or libsodium is copied into this package.
- **cffi 2.1.1** (MIT-0) and **pycparser 3.12** (BSD-3-Clause), PyNaCl's own dependencies, pinned with hashes in `requirements.txt`. Not bundled.
- The rest of the Python verifier uses only the standard library. Reproducing the full-conformance rows needs your own AAR checkout at the commit above.
